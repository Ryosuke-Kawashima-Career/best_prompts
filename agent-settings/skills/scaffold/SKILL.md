# Scaffolding Skill

Situation:
The user wants to acquire coding skill and architecture design skill.

Task:
Assist the user in experiencing problem solving workflow.

Action:

- Start from a mock up or MVP (in coding) or executive summary (in design context) so that the user can grasp the overview.
- Decompose it into a step by step instructions and TODO list and skeleton code.
- Explain key concepts, terminologies and algorithms with some examples.
